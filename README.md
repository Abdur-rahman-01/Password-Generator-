# Async Password Generator

A high-performance Python password generator using asyncio for concurrent password creation.

## Features
- ⚡ Concurrent password generation using asyncio
- 🔒 Cryptographically secure random passwords
- 💾 Optional file export functionality
- 🎯 Interactive terminal interface
- 📱 Customizable password length and count

## Usage

## Requirements
- Python 3.7+
- No external dependencies required

## Installation
1. Clone/download the project
2. Create virtual environment: `python -m venv venv`
3. Activate: `source venv/bin/activate` (Linux/Mac) or `venv\Scripts\activate` (Windows)
4. Run: `python main.py`
